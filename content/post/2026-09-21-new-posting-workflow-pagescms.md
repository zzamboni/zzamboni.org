The main posting workflow for my blog is using Org-mode and ox-hugo. This is amazingly powerful, but it needs me to be at my laptop in Emacs, so I've been looking for a simpler posting workflow for when I want to create short posts from anywhere, including my phone. [Pages CMS](https://pagescms.org) seems very promising! I installed it in my blog and this is my first test post.
