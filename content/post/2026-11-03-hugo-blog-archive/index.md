I recently added a [blog archive](/archive/) to this site: a compact list of posts grouped by year, with a small posts-per-year chart at the top. Clicking a bar jumps to that year's entries. It is a useful way to browse older posts without paging through summaries and images.

Once it was working, I realized that very little of it needed to be specific to my website. I extracted it into [`hugo-blog-archive`](https://github.com/zzamboni/hugo-blog-archive), a reusable Hugo module.


## A small feature that travels well {#a-small-feature-that-travels-well}

The module renders the list and chart together, so their counts come from the same filtered collection of posts. Years with no posts remain visible in the chart, and the default ordering puts the newest posts first.

Everything is generated by Hugo at build time. There is no JavaScript charting library to load: the bars are HTML and CSS, and the year links are ordinary anchors. The chart scrolls horizontally on narrow screens.

I use [Blowfish](https://blowfish.page/), so the module includes an optional style that follows its colors and light/dark appearance. The default styling works independently of Blowfish, inherits the site's fonts, and can be adjusted with CSS variables. The site's own theme still provides the surrounding page.


## Adding an archive {#adding-an-archive}

For a site already using Hugo Modules, add this to `hugo.toml`:

```toml
[[module.imports]]
path = "github.com/zzamboni/hugo-blog-archive"
```

Then resolve the dependency:

```sh
hugo mod get github.com/zzamboni/hugo-blog-archive@main
```

Create `content/archive.md` with a title and the `archive` shortcode:

```markdown
+++
title = "Blog archive"
+++

{{</* archive */>}}
```

By default, the archive includes the `post` and `posts` sections. My site's configuration selects `post`, excludes photo posts, and enables the Blowfish palette:

```toml
[params.blogArchive]
sections = ["post"]
excludeTags = ["photos"]
style = "blowfish"
```

The chart, ordering, and date format are configurable too. Hugo's normal draft and publication rules still apply.


## Try it {#try-it}

You can compare the [generic example](https://zzamboni.github.io/hugo-blog-archive/generic/archive/) and the [Blowfish example](https://zzamboni.github.io/hugo-blog-archive/blowfish/archive/), which use the same sample content.

The [repository](https://github.com/zzamboni/hugo-blog-archive) has installation instructions, configuration options, and examples for custom layouts. It is MIT-licensed. If you have wanted a straightforward archive for your Hugo site, give it a try!
